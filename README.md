## Launch

Запускать через через http профиль аппхоста. В самом аппхосте можно настроить количество и вид продюсеров

## Настройки

В аппсетингах проекта можно подашаминть настройки как потрибителя так и продюсера - количество клиентов, количество генерируемых тиков, дюбликатов и т.д.

## Нюансы

Есть вещи которые можно улучшить, которые я либо упростил либо счел нецелесообразным в контексте тестового задания - TTL для хранящихся дубликатов тиков, использование ОРМ для бд, более отказоустойчивая очередь пишущая в бд, интеграционные тесты для проверки записи в бд, 
реализация полной CleanArchitecture где подразумевается разделять слои на отдельные сборки

## Что использовал

Rider, Docker, Cursor (plan + agent mode)
